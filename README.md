# 🌱 Nature-32C: Coral Image Classification

## 📖 Overview
---
Welcome to **Nature-32C**, a comprehensive repository for coral reef image classification using cutting-edge deep learning techniques. This project leverages **ResNet-50** and other machine learning methodologies to classify coral reef images based on their health status, aiding in marine conservation efforts. 🌊🐠

### 🌊 Protecting Our Oceans
---
By classifying coral reef health, **Nature-32C** contributes to efforts in marine conservation. Together, we can make a difference for the planet and its underwater ecosystems! 🌍🐟

## 🚀 Key Features
---
- **Deep Learning Models**: Implements ResNet-50 for robust image classification.
- **Preprocessed Datasets**: Includes train and test datasets for streamlined experimentation.
- **Comprehensive Notebooks**: Jupyter notebooks for model training, evaluation, and experimentation.
- **Research Insights**: Detailed analysis and visualizations for understanding coral reef health.

## 📂 Repository Structure
---
- **`Nature@32C.pdf`**: Project documentation and research report.
- **`classification.ipynb`**: Notebook for initial data analysis and classification experiments.
- **`resnet50-corals-image-classification.ipynb`**: Advanced implementation of ResNet-50 for coral classification.
- **`train.csv`**: Training dataset for model development.
- **`test.csv`**: Test dataset for model evaluation.

## 📊 Project Workflow
---
1. **Data Preparation**:
   - Load and preprocess coral reef images.
   - Split data into training and testing sets.
2. **Model Development**:
   - Experiment with ResNet-50 architecture.
   - Tune hyperparameters for optimal performance.
3. **Evaluation**:
   - Assess model accuracy and F1-score.
   - Generate confusion matrices and classification reports.
4. **Insights**:
   - Visualize results and analyze model predictions.

## 🛠️ Getting Started
---
### Prerequisites
- Python 3.8 or above
- Jupyter Notebook
- Required libraries (install via `requirements.txt`):
  ```bash
  pip install -r requirements.txt
  ```

### Running the Project
1. Clone the repository:
   ```bash
   git clone https://github.com/Nikhil-Doye/Nature-32C.git
   ```
2. Navigate to the repository:
   ```bash
   cd Nature-32C
   ```
3. Open Jupyter Notebooks:
   ```bash
   jupyter notebook
   ```
4. Explore and run notebooks:
   - `classification.ipynb`
   - `resnet50-corals-image-classification.ipynb`
